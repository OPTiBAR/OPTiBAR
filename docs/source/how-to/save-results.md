Save the drawings and results
=============================

After a calculation, the buttons of **3. Results** save its outputs.
Each one asks for a file name.

* **DXF Drawing** saves the detailing map. Open it in any CAD program; to get a DWG file, save it as DWG from AutoCAD, AutoCAD LT or BricsCAD.
* **PDF Drawing** saves a compact A4 sketch, for a quick check.
* **Save Results** saves the full result as a JSON file, and a readable summary next to it, for example `foundation_calculation.json` and `foundation_calculation_summary.txt`. Attach the summary to a report; use the JSON file to post-process the result.

[Outputs](../reference/outputs.md) describes the content of each file.

To stop a calculation that takes too long, press **Stop**.
Loading a new input file clears the results.
