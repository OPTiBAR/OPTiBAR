استفاده از OPTiBAR در Python¶

موتور محاسبه را می‌توان بدون برنامه به کار برد، مثلاً برای آرماتوربندی چندین فونداسیون در یک اسکریپت.

اجرای یک محاسبه¶

فایل SAFE را بخوانید، محاسبه را اجرا کنید و نقشه‌ها را بنویسید:

from optibar.core.parser.parse import V16Parser
from optibar.core.run import run_calculation
from optibar.core.sketch.dxf import DxfDrawing
from optibar.core.sketch.sketch import Sketch

parser = V16Parser("foundation.accdb")
foundation = parser.get_foundation()
parser.close()

config = {
    "diameter": {"typical": 18, "additional": 25, "thermal": 12, "shear": 14},  # mm
    "typical_arrangement": {"method": "INTERVAL", "value": 0.2},               # m
    "side_cover": 0.05,                                                          # m
    "elimination": {"additional": 0.2, "shear": 2.0},                           # m
    "type_number": {"total": 20, "stack": 2, "shear": 4},
}
output = run_calculation(foundation, config)

if "errors" in output:
    print("not feasible:", output["errors"])
else:
    DxfDrawing(output["data"]).save("foundation.dxf")
    Sketch(output["data"]).save("foundation.pdf")

تنظیمات همان تنظیمات برنامه هستند، بر حسب متر؛ تنظیمات را ببینید. خروجی ساختار کلید result فایل نتایج را دارد؛ خروجی‌ها را ببینید.

Read the tables from somewhere else¶

V16Parser takes the path of an Access file, or a table source that returns SAFE's tables. MemorySource holds tables already in memory, for example tables read from another export: a dict from the table name, as SAFE writes it, to a list of rows, each a dict from the column name to the value. The tables and columns are those of SAFE input, with values in the units of Program Control:

from optibar.core.parser.parse import V16Parser, MemorySource

tables = {
    "Program Control": [{"CurrUnits": "Tonf, m, C"}],
    "Grid Lines": [{"AxisDir": "X", "GridID": "A", "Ordinate": 0.0}, ...],
    ...
}
foundation = V16Parser(MemorySource(tables)).get_foundation()

A missing table or column raises TableMissingError, as it does for an Access file.

خروجی گرفتن از نتایج به صورت جدول¶

optibar.core.export.export جدول‌های جدول‌های خروجی را با قالبی که پسوند فایل تعیین می‌کند می‌نویسد: .xlsx، .zip (فایل‌های CSV) یا .json. ورودی آن نتیجه است، به همان شکلی که فایل نتایج آن را نگه می‌دارد:

from optibar.core.export import export

saved = {"calc_type": "calculation", "config": config, "result": output, "input_file": "foundation.accdb"}
export(saved, "foundation.xlsx")

optibar.core.export.prepare خود جدول‌ها را برمی‌گرداند تا در Python از آن‌ها استفاده شود. از فایل نتایجی که برنامه ذخیره کرده هم می‌توان به همین روش خروجی گرفت، پس از خواندن آن با json.load.

اجرای یک تحلیل¶

type_number["total"] و type_number["stack"] را به‌صورت بازه بدهید، مثلاً {"from": 10, "to": 20}، و optibar.core.run.run_analysis را با همان آرگومان‌ها فراخوانی کنید. این تابع برای هر ترکیب یک نتیجه برمی‌گرداند، یا {} برای ترکیب‌هایی که شدنی نیستند.
